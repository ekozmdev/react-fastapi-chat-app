# 要件定義書

## プロジェクト概要

**主目的**: OpenAI Agent SDK でのツール実行UIの構築

このプロジェクトは、OpenAI Agent SDK を使用してツール実行を可視化し管理するインタラクティブなユーザーインターフェースの作成方法を実演します。システムは、ツール呼び出し中のリアルタイムフィードバック提供と、ツール結果のユーザーフレンドリーな表示に焦点を当てています。

## 主要要件

### 1. ツール実行の可視化

**目的**: AIのツール実行をユーザーにとって透明で理解しやすくする

**要求事項**:
- AIがツールを呼び出すことを決定した瞬間の検出
- ツール実行中の視覚的インジケーター表示（スピナー、プログレス）
- ツール実行結果の整理された形式での表示
- ツール実行詳細への容易なアクセス提供

**成功基準**:
- ツール実行開始を1秒以内で検出
- 実行中の明確な視覚的フィードバック
- 90%以上のツール結果が適切に表示

### 2. リアルタイムストリーミング統合

**目的**: ツール実行をテキストストリーミングとシームレスに統合

**要求事項**:
- 複数のイベントタイプ（tool_called, tool_output, text_delta）の処理
- イベント順序の一貫性維持
- ツールイベントとAIテキスト応答の協調
- イベントの欠損や重複の回避

**成功基準**:
- 100%正確なイベントタイプ分離
- 100ms未満のストリーミング遅延
- イベント順序違反ゼロ

### 3. 混合セッション管理

**目的**: ツール使用と通常チャットが混在する会話をサポート

**要求事項**:
- ツール実行記録の会話履歴への保存
- セッション再開時のツール情報復元
- ツール実行間での文脈継続性維持
- ツールデータを含む会話削除の処理

**成功基準**:
- 100%のツール実行記録永続化
- 100%のツール情報付きセッション復元
- シームレスな文脈継続性

### 4. ツール結果表示

**目的**: ユーザーの理解のためにツール結果を効果的に提示

**要求事項**:
- ツール結果専用表示エリア
- 詳細なツール情報閲覧用サイドバー
- 適切なフォーマッティングによる長文結果のサポート
- 構造化コンテンツのMarkdownレンダリング

**成功基準**:
- 全ツール結果の適切な表示
- サイドバー表示の1秒以内応答
- 95%以上のMarkdownレンダリング精度

### 5. 開発者学習支援

**目的**: 開発者がツール実行UI実装を理解できるよう支援

**要求事項**:
- 包括的なログとデバッグ情報
- API呼び出しの可視化
- 詳細なエラー報告
- パフォーマンスメトリクスの表示

**成功基準**:
- 100%のAPI呼び出しログ記録
- 90%以上のエラー原因特定
- デバッグ情報の即座表示

## 機能要件

### ユーザーインターフェース

**チャットインターフェース**:
- 送信ボタン付きメッセージ入力エリア
- ユーザー/AI/ツール区別付きメッセージ履歴
- 会話履歴用の折り畳み可能サイドバー
- 詳細閲覧用ツール結果サイドバー

**ツール実行表示**:
- ツール実行中のスピナー/ローディングインジケーター
- チャットフロー内でのツール実行結果統合
- 詳細アクセス用「🔧 ツール実行結果」ボタン
- ツール実行内訳付き右サイドバー

**セッション管理**:
- 自動会話作成と管理
- 会話復元付きページリフレッシュ回復
- 適切なクリーンアップ付き会話削除
- URL ベース会話ナビゲーション

### バックエンドAPI

**認証**:
- JWT ベースユーザー認証
- トークンリフレッシュ付きセッション管理
- 保護されたルートアクセス制御

**チャットストリーミング**:
- リアルタイム通信用 Server-Sent Events
- ツール実行イベントストリーミング
- テキスト応答ストリーミング
- イベント完了通知

**データ管理**:
- 会話CRUD操作
- ツール実行記録を含むメッセージ保存
- ユーザー管理機能

### ツール統合

**利用可能ツール**:
- `get_current_time`: 現在のタイムスタンプ取得
- `calculate`: 安全な数学式評価
- `web_search`: モックWeb検索機能

**ツールアーキテクチャ**:
- OpenAI Agent SDK統合
- ツール実行監視
- 結果フォーマットと保存
- エラーハンドリングと回復

## 技術制約

### 技術スタック

**フロントエンド要件**:
- TypeScript付きReact 18以上
- モダンブラウザサポート（Chrome, Firefox, Safari, Edge）
- Server-Sent Eventsサポート
- JavaScript有効

**バックエンド要件**:
- Python 3.13以上
- FastAPIフレームワーク
- PostgreSQLデータベース
- OpenAI APIアクセス

**インフラ**:
- コンテナ化用Dockerサポート
- リバースプロキシ用Nginx
- 環境変数設定

- OpenAI APIキー必須
